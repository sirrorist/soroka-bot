# Soroka - бот для скачивания видео

Современный Telegram бот для скачивания видео, фото и текста из популярных платформ.

## Поддерживаемые платформы
- TikTok
- YouTube
- Instagram
- X.com (Twitter)
- Reddit
- Pinterest

## Технологии
- **Python 3.11+**
- **aiogram 3.x** - современный асинхронный фреймворк для Telegram ботов
- **yt-dlp** - универсальный загрузчик видео
- **FastAPI** - для веб-интерфейса и API
- **PostgreSQL** - для хранения статистики и пользователей
- **Redis** - для кэширования и очередей
- **Docker** - для контейнеризации
- **Celery** - для фоновых задач

## Возможности монетизации
1. **Freemium модель**: бесплатно 7 скачиваний в день, премиум - безлимит
2. **Подписка**: месячная/годовая подписка через Telegram Payments
3. **Реклама**: показ рекламы между скачиваниями для бесплатных пользователей (пока не нужна)
4. **API доступ**: платный API для разработчиков (пока не нужна)

## Быстрый старт

📖 **Подробная инструкция**: [GETTING_STARTED.md](./GETTING_STARTED.md)

### Минимальная настройка

1. Получите токен бота у [@BotFather](https://t.me/BotFather)
2. Создайте `.env` файл на основе `env_template.txt`
3. Заполните `BOT_TOKEN` в `.env`
4. Запустите базу данных: `docker-compose up -d db redis`
5. Создайте таблицы: `alembic upgrade head`
6. Запустите бота: `python main.py`

## Конфигурация

Создайте `.env` файл на основе `env_template.txt` и заполните:
- `BOT_TOKEN` - токен от @BotFather (обязательно)
- `DATABASE_URL` - строка подключения к PostgreSQL
- `REDIS_URL` - строка подключения к Redis
- Остальные параметры опциональны
